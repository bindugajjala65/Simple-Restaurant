# Restaurant-simplewebsite

🍽️ Restaurant Website
This is a simple and responsive Restaurant Website created using HTML and basic CSS. The project is designed to practice core front-end concepts and build a visually clean layout suitable for beginners.

The website includes a structured navigation bar, a welcoming hero section, food menu with prices, today’s special section, image gallery, customer reviews, and a contact/reservation form. A footer section is also included for basic contact details.

This project focuses on:

Clean HTML structure

Basic CSS styling

Simple layout design

Beginner-friendly front-end development

🛠️ Technologies Used
HTML5

CSS3

✨ Features
Header with navigation menu

Welcome section

Food menu with pricing

Today’s specials

Image gallery

Customer reviews

Contact / reservation form

Footer with contact information

This project helped me improve my understanding of HTML structure, CSS styling, and website layout design.
